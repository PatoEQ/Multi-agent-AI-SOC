# Code of Conduct

This project follows the spirit of the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:**

- Be respectful and welcoming, whatever someone's experience level.
- Give constructive feedback on ideas and code, not on people.
- No harassment, discrimination, or personal attacks.
- Never share other people's private data, or real incident data, in issues or PRs.

Report unacceptable behaviour privately to the maintainer through GitHub
(@PatoEQ). Maintainers may remove comments, commits or contributors that do not
follow these rules.
